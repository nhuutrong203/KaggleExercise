# KaggleExercise

A personal collection of beginner-friendly Kaggle practice projects for improving Machine Learning, Deep Learning, NLP, and data preprocessing skills.  
This repository is designed as a learning roadmap, starting from basic regression and classification problems, then moving toward recommender systems, time-series forecasting, and chatbot development.

## Project List

### 1. House Price Prediction  
**Type:** Regression  

This project focuses on predicting house prices based on different numerical and categorical features.  
It is a classic beginner-friendly machine learning problem for practicing data preprocessing, feature engineering, missing value handling, and regression modeling.

**Main skills:**
- Data cleaning
- Missing value handling
- Feature engineering
- Regression models
- Model evaluation

---

### 2. Credit Card Fraud Detection  
**Type:** Classification / Imbalanced Data  

This project focuses on detecting fraudulent credit card transactions.  
It is useful for learning how to handle imbalanced datasets and evaluate classification models properly beyond simple accuracy.

**Main skills:**
- Binary classification
- Imbalanced data handling
- Precision, Recall, F1-score
- Confusion matrix
- ROC-AUC evaluation

---

### 3. MovieLens Recommender System  
**Type:** Recommendation System  

This project introduces the basic idea of recommender systems using movie rating data.  
It focuses on collaborative filtering and helps build an understanding of how recommendation engines suggest items to users.

**Main skills:**
- Collaborative filtering
- User-item interaction analysis
- Similarity-based recommendation
- Recommendation logic

---

### 4. Bitcoin Price Prediction using LSTM  
**Type:** Time Series Forecasting / Deep Learning  

This project focuses on predicting Bitcoin prices using time-series data and LSTM models.  
It is suitable for practicing sequential data processing and moving from traditional machine learning to deep learning.

**Main skills:**
- Time-series preprocessing
- Sequence creation
- LSTM model building
- Forecasting
- Deep learning workflow

---

### 5. Chatbot using LSTM  
**Type:** NLP / Deep Learning  

This project focuses on building a simple chatbot using deep learning.  
It introduces basic NLP preprocessing steps such as tokenization, padding, sequence modeling, and response prediction using LSTM.

**Main skills:**
- Text preprocessing
- Tokenization
- Padding sequences
- LSTM for NLP
- Basic chatbot development

---

## Learning Goal

The main goal of this repository is to build a strong foundation in machine learning through practical Kaggle projects.  
Each project focuses on a different problem type, helping me improve step by step from basic ML techniques to more advanced deep learning applications.
